# Project Rules

## Frontend-Only Customizations & Visual Transformation
- **Strict Limitation**: Never modify backend code (PHP controllers, models, routes, or database schemas/queries). Only modify Blade views, CSS, client-side JavaScript, and HTML elements.
- **Visual Rebranding**: Change all hardcoded page titles, text contents, headers, and layout styling so the project's identity is completely transformed.
- **Methodical Execution**: Process the changes page-by-page. Review the layout, sub-pages, and components associated with one page before moving to the next.
